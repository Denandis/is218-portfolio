01The question & who it's for

Question. Which AI direction fits me best right now — building AI solutions in the field (Forward-Deployed / Applied AI Engineering) or building AI inside healthcare — and what do real employers actually ask for?
Reader. An early-career candidate like me — an NJIT student weighing AI directions in the NY/NJ area. It also has to work for a recruiter skimming in under a minute.

Eligibility & my gaps (honest):
  • Palantir FDE — wants a degree + ~1 yr experience and strong communication; some roles need U.S.-person status/clearance. Gap: I'm still a student; need more production + customer-facing work.
  • Apple ML Engineer — senior, deep ML, often publications. Gap: above entry level; I'd target a junior ML role and build real ML depth first.
  • Optum AI/ML — ~3+ yrs, Master's preferred, LLMs/Databricks, healthcare data. Gap: need the degree + ML/cloud practice. Advantage: I already work in healthcare (Optum).
Personal eligibility circumstances stay in my private Canvas reflection, per the assignment.

03Two directions compared — and my lean

A — Applied / Forward-Deployed AI Engineering

Embed with customers, build & deploy AI fast. Python + full-stack + strong communication. High pay, very competitive, true entry-level roles are rare.

B — AI in Healthcare  ⟵ my lean

Build AI/ML for health systems (claims, patient data). Python + ML/LLMs + healthcare data & compliance. I already work at Optum — a real, rare domain advantage, and a huge employer in my area.

I'm leaning Direction B near-term because my pharmacy/Optum experience is a genuine edge — while deliberately building the Python + communication strengths that keep Direction A open. My portfolio projects will have a healthcare-AI flavor.

04Two brand / layout directions

Direction 1 — "Field Guide"
Clean, editorial, numbered sections, one accent color, scannable cards. Reads like a printed reference. Best for helping a reader choose.
Direction 2 — "Builder / Terminal"
Dark theme, monospace accents, projects & GitHub front and center. Best for impressing a recruiter fast.

Plan: prototype both heroes, get peer feedback, then pick. Current lean — Field Guide for research, Builder for the portfolio home.

05User stories

  1. As a recruiter, I want to see top skills and projects within a minute so I can judge fit quickly.
  2. As a fellow student, I want two AI directions compared with real postings so I can choose one to aim at.
  3. As a skeptical reader, I want to open the actual postings cited so I can trust the claims.
  4. As a learner, I want to see which skills repeat so I know what to study next.
  5. As Nandish, I want the site to link my GitHub and LinkedIn so readers can verify my work.
